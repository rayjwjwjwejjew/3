## 范围与可复现命令

- 数据源：Baostock 日线前复权数据。
- 样本：60 只上海 A 股普通股票；2025-01-01 至 2026-07-29。
- 处理结果：22,800 条 bars、**575** 条日历记录、8,863 条 stock_basic 记录。

```bash
python -m src clean
python -m src validate --asof 2026-07-29
python -m src backtest --initial-cash 1000000 --out results/real_sample_nav.csv --no-rich
python -m src overfit --split-date 2025-10-01 --out results/real_sample_overfit.csv
```

`validate` 返回 `OK (0 findings)`：重复键、正价格、成交量、上市前数据、未来数据与日历检查均未发现问题。

## §2.1 关键 4 数字

| 指标 | 真实样本结果 | 判断 |
| --- | ---: | --- |
| 总收益 | -17.27% | 未通过；不能证明策略有效 |
| 夏普比率 | -0.83 | 未通过；低于 0 |
| 最大回撤 | -18.37% | 数值在常见区间内，但截至样本结束仍未修复 |
| 成本/收益 | 2.62% | 成本模型有输出；不是收益失效的主要解释 |

附加证据：19 次调仓、141 个订单（140 成交、1 拒绝）、年化换手 692.33%。

## 稳健性结果

- 样本内：-16.56%，夏普 -1.32；样本外：-18.10%，夏普 -0.34。
- 5/10/20 日调仓均为负；5 日虽是三者中损失最小（-9.45%），但成本/收益升至 14.57%，不能据此选参。
- 110/120/130 日 lookback 均为负，说明没有出现“只靠一个尖峰参数盈利”的假象，但也没有有效策略证据。
- 成本翻倍后收益从 -17.27% 降到 -17.59%，成本/收益从 2.62% 升到 5.13%。

## 严格结论

此结果**不是**对 A 股动量的普遍否定：样本只覆盖 60 只上海股票和约 19 个月，且不是冻结的全市场点时样本。它只足以说明：本 V1 默认参数在此真实样本上没有通过最低可信度门槛。

下一次研究必须使用股票型全市场池、冻结的数据快照、独立样本外区间，并补充 DSR、CSCV/PBO 和锁定 OOS；在此之前保持 `RESEARCH_ONLY`、不连接券商、不生成订单。
