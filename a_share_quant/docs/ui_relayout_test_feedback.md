> 执行日期：2026-07-29  
> 对应提交：`3baa7f9`  
> 范围：Streamlit 研究工作台的信息架构与视觉层；**不改变策略、数据处理或交易权限**。

## 1. 本轮重排目标

原界面把页面导航、实验参数和结果混在同一侧边栏与纵向页面中。此次改为三层：

1. **应用身份层**：标题、数据来源和“研究用途 / 不连接券商”边界在第一屏可见。
2. **工作区层**：顶部横向导航分为“总览、回测明细、行情观察、稳健性、执行边界”。
3. **实验配置层**：侧栏只保留可折叠的规模、策略、资金与复现参数。

总览采用“结论优先”顺序：关键指标 → 净值与基准 → 研究判断与风险信号。

## 3. 反馈

### 已改善

- **页面定位更清楚**：导航从侧栏移到内容顶部，用户不会把“切换页面”和“改变实验参数”混为同一种操作。
- **结论更早出现**：总览的“研究判断”把负夏普、未修复回撤等信息放在图表旁边，避免只看到净值线就作结论。
- **安全边界更显性**：数据来源和“研究用途 / 不连接券商”作为状态标签常驻首屏，不依赖用户进入执行页才看到。
- **视觉层级更稳定**：标题、KPI、表格、风险卡与按钮采用一致的间距、透明材质和即时按压反馈；在减少动态时会退化为静态反馈。

### 仍需注意

- 本轮验证重点是 UI 与现有页面逻辑；它**不是**真实全市场回测、样本外或模拟盘验证。
- 浏览器自动化已验证“总览 / 回测明细”主路径；其余三个工作区仍应在下一次视觉回归中分别覆盖桌面与窄屏。
- 当前 KPI 的数据范围仍需更直白：即使真实数据已选中，也应展示股票池、起止日期、数据哈希和基准来源，防止把局部样本误读为全市场结论。

## 4. 建议（按优先级）

1. **P0：加“本次实验摘要”卡片**  
   在总览首屏显示 `数据模式 / 股票数 / 起止日期 / 基准 / 数据快照 ID`，并与导出 CSV 一起写入 metadata。

2. **P1：把稳健性结果改成可比较图表**  
   目前是三张表。下一版应按“调仓频率、回看期、成本压力”各用一张柱状或点线图，并突出默认参数所在位置；不要用颜色暗示“盈利”。

3. **P1：建立视觉回归清单**  
   固定五张桌面截图和一张窄屏截图，覆盖五个工作区、真实/合成数据状态、长表格与风险告警。每次 UI 修改后人工检查一次。

4. **P2：减少表格阅读负担**  
   回测明细可把低频字段折叠进“交易统计”，把年化收益、夏普、最大回撤、成本保留在首屏。该改动只在用户确认常用字段后执行。

## 5. 当前结论

本次 UI 重排已经通过局部自动化和浏览器主路径验证，适合继续作为研究工作台使用。它改善的是阅读、导航和风险提示，**不提高策略可信度，也不授权交易**。
