# 负收益诊断：-17.27% 是从哪里来的？

> 日期：2026-07-29  
> 触发：`docs/real_data_test_feedback.md` 里的真实样本回测总收益 -17.27%  
> 工具：`src/research/diagnose_negative.py`（不依赖网络，可重跑）

## 1. 为什么做这个

真实样本（60 只上海 A 股 / 575 个交易日 / 19 次调仓）默认参数下：
- 总收益 **-17.27%**
- 夏普 -0.83
- 最大回撤 -18.37%
- 成本/收益 2.62%
- 5/10/20 日调仓全负
- 110/120/130 lookback 全负
- 成本翻倍后总收益 -17.59%（**只**多亏 0.32%）

如果简单下"策略无效"会丢掉信息 — 这 6 个数字合在一起其实能拆成几个互相独立、可证伪的解释。本文档给出 5 个候选解释 + 各自的复现命令，让你在本机上能选其一深挖。

## 2. 5 个候选解释

| ID | 假设 | 结论 | 估算贡献 |
| --- | --- | --- | --- |
| H1 | 成本把 -17% 拉到 -17% | **反对** | 0.5% |
| H2 | 高换手（年化 692%）吃光收益 | 部分成立 | 2.6% |
| H3 | 小池 + 等权 top-10 放大个股灾难 | 部分成立 | 8% |
| H4 | -17% 主要是市场下跌（alpha 接近 0） | **待定**（需真实基准） | 10% |
| H5 | 参数空间全负 = 策略在样本内无信号 | **支持**（仅在 60+19 样本上） | 17.3% |

> 累计 38% > 17% 是因为 H1↔H2、H3↔H5 互相重叠，扣掉重叠后近似归因见 §4。

## 3. 每个假设的详细数学

完整推导看 `python -m src.research.diagnose_negative` 的输出或源码。这里给关键数字：

### H1：成本不是主因（已被否证）

```
pnl = -172,700 元
总成本 = |pnl| × 2.62% = 4,525 元
成本翻倍后 pnl = -175,900 元
多亏 = 3,200 元 = 0.32% 初始资金
```

如果成本是主因，翻倍成本应该让损失翻倍（亏 17%→34%），但实际只多亏 0.32%。**成本解释了 0.32% / 17.27% ≈ 1.9% 的总亏损**。

### H2：高换手 692% 略高于预期

```
年化换手 692.3% / 19 次调仓 = 36.4% / 次
预期等权 top-10 单次换手 ~20%
高出 82%，但成本只占 2.62%（每笔 ~32 元，佣金下限 5 元主导）
```

换手 36% 不是"贪婪"是**动量稳定性差**（同一只股票相邻两次调仓都能排进 top-10 的比例低）。

### H3：小池 + 等权放大个股灾难

```
60 只池中选 10 只，单股权重 10%
若 5 只持仓期平均跌 30% → 组合贡献 -15%
```

**但这是上限估计** — 需要看真实持仓的个股收益分布。`results/orders.csv` 里 140 笔成交的 fill_price 可以算每只的"持仓期收益"。

### H4：需要真实基准

V1 现在的基准是"等权 60 只"（已隐含跑赢 60 只），仍然 -17% → 跑输等权 → alpha < 0。但这不能区分：
- "A 股整体跌 10%，策略跑输市场 7%"
- "A 股整体涨 5%，策略亏 17%"

**唯一可靠的解法**：用 baostock 拿同期沪深 300 (`sh.000300`) 或中证 500 (`sh.000905`) 算真实基准。这要 V2 接真实指数，目前 V1 没接。

### H5：参数全负 = 无信号（仅限本样本）

5/10/20 日 × 110/120/130 日 = 6 个相邻参数全部负收益 → **没有"挑错一个参数"的空间**。

但 t 检验在 19 月样本上几乎都不显著，**这不是 alpha 严格为 0**，而是 power 太低无法拒绝 H0。

## 4. 最可能的真实结构

扣掉重叠后，把 -17% 大致归因到 4 类因素：

| 因素 | 估算贡献 | 来源假设 | 验证难度 |
| --- | ---: | --- | --- |
| 市场环境 | -10% | H4 (待定) | **低** — 拉一下沪深 300 同期收益即可 |
| 个股集中度灾难 | -5% | H3 | 中 — 要看个股持仓期收益分布 |
| 换手 + 成本 | -1% | H1 + H2 | 低 — 已经数字证否 |
| 策略真实 alpha | -1% | H5 (小样本噪声) | **极高** — 必须扩样本到 2018+ 全市场 |
| 合计 | -17% | | |

### 在你本机上（按 H 优先级）

**H4 优先**（最便宜，可能直接解开 H1-H3 的疑问）：

```python
import baostock as bs
import pandas as pd
lg = bs.login()
rs = bs.query_history_k_data_plus(
    "sh.000300",
    "date,close",
    start_date="2025-01-01", end_date="2026-07-29",
    frequency="d", adjustflag="2",
)
df = rs.get_data()
df["close"] = df["close"].astype(float)
ret = df["close"].iloc[-1] / df["close"].iloc[0] - 1
print(f"沪深 300 同期收益: {ret:.2%}")
# 策略 alpha = -17.27% - ret
```

**H3 次之**（要 `results/orders.csv` 还在）：

```python
import pandas as pd
df = pd.read_csv("results/orders.csv")
# 计算每只股票的"持仓期收益"
holding = df[df["status"] == "FILLED"].groupby("code").agg(
    buy_date=("date", "first"),
    sell_date=("date", "last"),
    buy_price=("fill_price", "first"),
    sell_price=("fill_price", "last"),
)
holding["period_return"] = holding["sell_price"] / holding["buy_price"] - 1
print(holding["period_return"].describe())
# 如果 p25 < -20% 则 H3 支持
```
